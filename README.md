# 🍕 San Remo 1 - Pizzeria Italienne

Bienvenue sur le dépôt du site vitrine pour la **Pizzeria San Remo 1**, un projet fictif (ou réel) conçu pour mettre en avant mes compétences en développement web front-end.

## 🔗 Voir le site en ligne
Vous pouvez consulter le site directement dans votre navigateur, sans rien télécharger, via le lien GitHub Pages suivant:

👉 **[Accéder au site San Remo 1](https://hasanna995.github.io/site-san-remo-1/)**

## 🛠️ Technologies utilisées
Ce projet a été réalisé en utilisant les technologies web standards :
*   **HTML5** : Pour la structure sémantique du site.
*   **CSS3** : Pour la mise en page, le design, les animations et le responsive (Flexbox/Grid).
*   **Google Fonts** : Pour une typographie soignée (Montserrat & Cormorant Garamond).
*   **GitHub Pages** : Pour l'hébergement gratuit et le déploiement continu.

## ✨ Fonctionnalités
*   Design moderne et épuré aux couleurs de l'Italie.
*   Interface 100% responsive (adaptée aux mobiles, tablettes et ordinateurs).
*   Navigation fluide avec défilement doux.
*   Structure optimisée pour le référencement (SEO) de base.

## 📂 Structure du projet
*   `index.html` : Le fichier principal contenant la structure et le style du site.
*   `README.md` : Ce fichier de présentation.
